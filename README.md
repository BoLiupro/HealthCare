## Overview

**软件天使 (HealthCare)** is a convenience-oriented healthcare software project developed for a university software innovation competition. The repository preserves the original implementation and project materials as part of our undergraduate software-engineering work.

## Team

- **Bo Liu**
- **Zeng Yiyun**

## Project Goal

The project explored how a mobile/software system could support everyday healthcare-service scenarios through a more accessible digital workflow. It was developed as a team engineering project rather than a research-paper codebase.

## Repository Notes

The code reflects the original competition-stage implementation and may include environment-specific configuration, dependencies, or assets. Please inspect the project configuration before reproducing it on a new machine.
